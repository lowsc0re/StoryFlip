# Embedded Font Notices

`sf_fonts.c` contains unmodified font data for:

```text
u8g2_font_helvB08_tf
u8g2_font_helvR08_tf
```

under local symbol names.

The data comes from:

```text
lib/u8g2/u8g2_fonts.c
```

in Momentum Firmware commit:

```text
d3f89dfe2ef6b01839201598e9be1590cba80322
```

Source:

https://github.com/Next-Flip/Momentum-Firmware/blob/d3f89dfe2ef6b01839201598e9be1590cba80322/lib/u8g2/u8g2_fonts.c
